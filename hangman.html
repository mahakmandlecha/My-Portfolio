Hangman Game

Project information

  • Category: Desktop Application
  • Motive: An interesting game that I made while learning Java.
  • Project date: October'2019
  • Project URL: https://github.com/mahakmandlecha/Hangman

Developed a command-line java-based Hangman game. The player has to correctly guess the hidden word by guessing the individual characters of the word. And designed an animated Hangman character whose body parts appear as the player makes the incorrect choice
